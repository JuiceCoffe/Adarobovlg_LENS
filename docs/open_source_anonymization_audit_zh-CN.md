# 匿名开源发布前仍需项目负责人处理的事项

> **临时文档：** 本文件只用于发布前收尾，可能包含对隐私风险和本地工作区状态的说明。正式公开仓库前应删除本文件，并确认它未进入公开 Git 历史或发布压缩包。

## 清理边界

匿名清理只针对本项目自行编写或本地新增、修改的内容，不针对第三方上游本身的作者信息和工程结构。

- 第三方上游仓库已有的源码、示例、注释、作者姓名、邮箱、版权声明、引用信息和目录结构应保留；这些内容属于来源归属，不视为本项目作者身份泄露。
- 不因上游源码中出现上游开发机路径、历史调试入口或非英文注释而单独删除代码。若这些内容妨碍运行，可在记录上游版本和本地补丁的前提下做必要修改。
- 缓存、构建产物、IDE 状态、嵌套 `.git/` 和明显的本地临时副本不属于需保留的上游源码，可从发布包排除。
- 只有能确认并非上游文件、且不被当前代码依赖的本地调试副本，才可删除。不得仅依据“当前服务没有调用”裁剪第三方上游源码。

## 公开发布前必须排除的文件

以下路径不应出现在公开 Git 仓库或发布压缩包中：

- `.agents/`、`.codex/`：本地 Codex/GitNexus 工作环境文件，与项目运行无关。
- `docs/open_source_anonymization_audit_zh-CN.md`：仅供发布前内部检查，可能暴露本地清理过程。
- `checkpoints/contact_graspnet/`、`checkpoints/dinov2/`、`checkpoints/hand_decision/`、`checkpoints/sam3/`、`checkpoints/xmem/`：实际模型权重约 5 GB，应通过 Hugging Face 分发，不应提交到源码仓库。公开仓库仅保留 `checkpoints/README.md` 和 `checkpoints/manifest.json`。
- `data/pointcloud/`：运行时生成的手部采样缓存，可由代码重新生成。
- `data/urdf/dh3_hand/.thumbs/`、`data/urdf/inspire_hand/.thumbs/`：USD 工具生成的预览缩略图缓存，不参与运行。
- `__pycache__/`、`*.pyc`、`*.egg-info/`、`build/`、`dist/`、日志、可视化视频及编辑器配置：若后续运行产生，发布前必须清除。
- `.env` 和其他本地环境配置：不得包含 API key、代理地址或私有服务配置；仅保留无真实凭据的 `.env.example`。

如果通过手工打包工作区发布，还必须排除顶层 `.git/`；如果通过正常 Git 提交和克隆发布，则无需删除工作仓库自身的 `.git/`。上述路径已加入 `.gitignore`，但 `.gitignore` 不能阻止已经被 Git 跟踪的文件进入历史，正式发布前仍需在完整 Git 仓库中检查跟踪状态和历史。

`assets/overview.png` 当前未被 README 或文档引用，可以作为可选清理项删除；它本身未发现个人信息，不属于必须删除项。第三方源码中的作者姓名、邮箱、版权与许可证属于上游归属信息，必须保留，不能作为匿名清理对象删除。

## 第三方代码的最终处理原则

第三方目录不做全量“匿名化改写”。最终发布时应：

1. 保留上游作者、版权、许可证、论文引用、示例源码及必要的上游目录结构。
2. 在 `docs/third_party.md` 记录上游 URL、固定版本、许可证、用途和本地修改。
3. 对本项目确实修改过的第三方文件，仅做运行兼容、安全性或集成所需的最小修改，并在来源文档中说明。
4. 不发布缓存、构建产物、IDE 配置、嵌套 Git 元数据和确认属于本地的临时副本。
5. 若上游未给出明确再分发许可，不自行套用本项目 MIT License；由项目负责人取得授权或决定不随仓库分发。

目前 `.agents/` 与 `.codex/` 是工作环境挂载目录，无法在当前会话中物理删除，但已被忽略。制作公开仓库或压缩包时必须确认它们未被包含。
